# Start here

For a new installation, follow [self-hosting](self-hosting.md). For an existing team workspace, ask its owner for the server address and an invitation. Feedbacks does not have public self-service registration.

Sign in, open a project and review its feedback. Owners manage members and allowed website origins. Install the [browser extension](extension.md) to capture pages and submit comments. Use [agent setup](agent-setup.md) for MCP access with a scoped credential.

In **People**, select one person to edit their account or project access. Expertise categories give agents context, while advanced feedback weighting changes preference summaries and does not grant permission. Disable an account before removing it from the People list. Owners can show removed accounts and restore them; restoration leaves login disabled until explicitly enabled. After creating a user, **Copy credentials and setup message** prepares a short private note with the installed app and Help links. New agent keys show their last four characters in Account so you can identify them; older hashed keys cannot recover that ending.
