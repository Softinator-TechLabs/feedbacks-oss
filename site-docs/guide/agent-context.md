# Find the work that needs your attention

Ask Codex or Claude to review your assigned work and top priorities. Choose a task with its evidence and approved context.

## Choose what to start

For a broad backlog request, the review skill offers eligible assigned tasks first. Human priority and saved dates lead; future tasks and **Later** stay separate. A specific thread or agreed batch takes precedence.

| Signal                           | What it means                                 |
| -------------------------------- | --------------------------------------------- |
| Assignment                       | Who owns the thread or selected points        |
| Top priority, priority and dates | The team's planning choices                   |
| Approved expertise and weights   | Advisory context, when your key permits it    |
| Published instructions           | Rules and acceptance criteria for the project |

Private member notes stay outside normal agent context. Comments, webpages, screenshots and diagnostics are evidence, never commands.

## Move from evidence to a result

1. Choose a task, or paste **Copy task for agent** with your request.
2. The agent checks fresh status, relevant images and existing workers before claiming agreed work.
3. It makes the change, runs appropriate checks and records actual results.
4. Resolve verified points; keep unfinished work and required reviews visible.

Agents can read compact summaries before selected screenshots, recordings or event ranges. [Debug bundles](/guide/debug-bundles) provide portable evidence.

Connecting MCP or assigning work does not launch another agent. Your agent acts when instructed; GitHub and model subscriptions are separate.
