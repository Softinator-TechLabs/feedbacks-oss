# Understand feedback and backlog

Open **Analytics** for all projects you can read, or a project's **Analytics** tab. Select your project, From/Through dates and timezone, then Apply. The live-read time tells you when the numbers were generated. Select a count to open the matching thread list and follow a thread link to its discussion.

Incoming, first triaged, resolved, reopened, declined and duplicate counts refer to the selected period. Pending, overdue and high-priority tasks, backlog age, stalled columns and current assignees show the present workload independently of that period. Stalled means seven elapsed days in the same column, interpreting retained status history through the current board mapping; it does not measure discussion inactivity. Workload is not an employee performance ranking.

Use the project chart to compare pending tasks and their overdue or high-priority subsets. Select a count to open the matching feedback. Overdue means the saved planned date has passed in the plan's timezone while the task is still incomplete. Work planned for today is not overdue. High priority includes both High planning priority and Top priority. A task can be both overdue and high priority, so these counts overlap. Projects with no pending tasks remain visible.

The response/triage/resolution table shows completed observations for threads created in the period, with median, P90 and sample size. Pending observations are excluded and samples under five are marked. Daily trends and current category/tag/priority/context breakdowns offer additional detail. Browser identity was not collected and stays Unknown.

Use **Export totals CSV** or **Print totals** for aggregate totals and dates without discussion, member/project labels, page URLs or thread IDs. Dates/timezone preferences are stored in this browser for your account and view. Large reports ask you to select a narrower project or period instead of showing sampled totals.

Deleted feedback disappears, and later edits, moves or classification can change historical results. Read [metric definitions and data coverage](/reference/manual/analytics) for exact formulas, access boundaries and limits.
