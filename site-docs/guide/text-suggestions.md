# Suggest the exact words

“Change the headline” still leaves room for interpretation. Select the phrase and write its replacement; Feedbacks keeps both versions with the page evidence.

<picture><source media="(max-width: 600px)" srcset="/media/story/text-mobile.svg" /><img src="/media/story/text.svg" width="760" height="320" alt="An illustrative suggestion replaces ‘every room’ with ‘your favourite corner’." /></picture>

## Make a suggestion

1. Start review with your connected extension on an approved website.
2. Select visible page text and choose **Suggest edit**.
3. Check **Original text**, enter **Suggested replacement**, then choose **Save suggestion**.
4. Open **Review & send**, check the suggestion and screenshot, then **Send feedback**.

An empty replacement requests deletion. You can edit the replacement again before sending. Inputs, editable regions and hidden/private content are excluded from selection.

## What the developer receives

The original wording, proposed replacement, selected text geometry, element context and screenshot stay in the thread and agent evidence. The suggestion is a local draft until sent; it never changes the live website itself.

In the screenshot editor and thread, **Show/Hide points**, **Show/Hide element outline** and **Show/Hide text selection** control separate visual layers. Hiding a layer changes the view, not the saved evidence. Older screenshots may have markers baked into the image.
