# Suggest the exact words

Select a phrase and propose its replacement, with the original wording and screenshot attached.

## Make a suggestion

1. Start review with your connected extension on an approved website.
2. Select visible page text and choose **Suggest edit**.
3. Check **Original text**, enter **Suggested replacement**, then **Save suggestion**. Leave it empty to request deletion.
4. Open **Review & send**, check the suggestion and screenshot, then **Send feedback**.

Revise the replacement before sending. Inputs, editable regions and hidden/private content are excluded. Review mode enables selection on pages that block it; leaving review or starting recording restores the site’s normal behavior.

## What the developer receives

The thread and agent evidence keep both versions, text geometry, element context and screenshot. **Suggestions stay local until sent and never change the live website.**

In the editor and thread, **Show/Hide points**, **Show/Hide element outline** and **Show/Hide text selection** control separate visual layers. Hiding one preserves the evidence. Older screenshots may have markers baked into their pixels.
