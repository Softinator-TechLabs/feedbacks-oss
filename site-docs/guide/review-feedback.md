Point at the change, check its original screenshot, then share it with your team.

## Capture {#capture}

1. Open the extension on your website. Right-click an element, write the change and choose **Save point**.
2. Repeat as needed. Each point keeps its original visible screenshot, including open menus and points now offscreen.
3. Choose **Review & send**. Check each image, revise notes and add drawing marks or an overall comment.
4. Choose **Send feedback**. Saved points remain local drafts until sending.

Use full-page capture when the whole page matters, [record a sequence](/guide/session-replay), or [suggest exact wording](/guide/text-suggestions). Review sensitive forms and frames before sharing; screenshot tools cannot redact video or separate diagnostic archives.

## Review a queue {#review-a-queue}

| Task               | Start here                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------- |
| Find the request   | Project **Feedback**: search, status and sort; **More filters** for page, domain and device |
| Continue reviewing | **Previous thread** / **Next thread** retain the queue filters; saved views remember yours  |
| Finish one point   | **Resolve point** / **Reopen point** with resolution permission; the thread stays open      |

Maintainers can remove and restore points without losing their original evidence. Resolving or declining the thread closes its active pins; reopening retains earlier individual decisions.

## Connect the outcome {#connect-the-outcome}

Reply to clarify the request. Record work status separately from optional review decisions. Add a real commit, PR or incorporated design as delivery evidence, then verify the result before resolving. A linked [GitHub Issue](/guide/github) does not prove the website changed.

::: details Formatting notes

Point notes, overall comments and replies support Markdown: bold, italics, links, lists and code. Embedded HTML and remote Markdown images are not rendered.

:::
