# Getting started

Feedbacks keeps visual website requests, screenshots, discussion and work status in a shared project. You can use an existing team server or [self-host your own](/guide/self-host).

## Join a team workspace

1. Ask a workspace owner for its exact HTTPS address and an invitation or assigned login. There is no public sign-up.
2. Sign in, open **Projects**, and choose your project. The **Feedback** tab is the review queue; **Documents**, **Surveys**, **Members**, **Instructions**, **GitHub**, and **Settings** contain their related tools.
3. Open a thread to see the request and its image/video evidence. Reply for discussion; change work status when the work actually moves.
4. Install the [Chrome extension](/guide/chrome-extension) to send feedback from the page you are reviewing.

You can create feedback from the project even without the extension. A maintainer controls approved website origins, membership and optional review rounds.

## What to do next

| Goal                             | Guide                                        |
| -------------------------------- | -------------------------------------------- |
| Capture a bug or design request  | [Chrome extension](/guide/chrome-extension)  |
| Triage a queue                   | [Capture and review](/guide/review-feedback) |
| Give an AI agent project context | [AI agents and MCP](/guide/mcp)              |
| Track work in a repository       | [GitHub Issues](/guide/github)               |

If a control is missing, check your project role with its maintainer. An agent token, browser session and Chrome extension pairing are separate credentials.
