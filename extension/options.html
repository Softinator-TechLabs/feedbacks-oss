Microphone access

Checking microphone permission…

Fix microphone or tab sound

First use: choose Allow microphone, approve Chrome’s prompt, then return to the website and start recording. This check immediately stops the microphone and saves no audio.

Previously blocked? Open Chrome microphone settings, find Feedbacks under “Not allowed”, and change it to Allow or remove its blocked entry. Chrome cannot show a new prompt while that permission is blocked. Return here and choose Check microphone again.

Your extension’s address:

Still blocked or unavailable? Select your input device in Chrome’s microphone settings. On macOS, allow Chrome in System Settings → Privacy & Security → Microphone. On Windows, enable microphone access for desktop apps in Settings → Privacy & security → Microphone. Restart Chrome if your computer requests it, then test again. A managed browser may require your administrator.

Tab sound uses the website tab’s audio, independently of the microphone. A silent website produces a silent track. In Chrome’s tab picker, enable Share tab audio. If a source is unavailable, you can explicitly turn it off above and record the remaining sources.

Keep page controls out of the way

Drag the grip to move the Feedbacks dock. Collapse the panel or hide it, then reopen the Chrome extension to restore it. Exit is always available on the dock. Pin the extension using Chrome’s puzzle menu for quick access.
