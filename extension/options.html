Capture UI changes and client feedback with the screenshots and context your developer’s AI agent needs.

A team server comes first. Your company installs Feedbacks once on its own infrastructure. Ask the owner for its address and your sign-in access. The extension connects to that server; it does not host one.

Server & account

In your team’s web app, open Setup → Copy server URL, then paste it here. Use the Feedbacks server address, not the website you are reviewing. Changing servers requires approval on that server.

Recent addresses can sync with your Chrome profile. Account tokens stay on this device. Uninstalling can erase local settings; reload an unpacked update to keep them.

Review defaults

Starting settings for each new review. Page controls let you change the current session.

Screenshot marker

The marker shows where you right-clicked. Your point and its screenshot are still saved when you choose No marker.

Recording defaults

Record video + session starts on the current tab. Session-only recording is available in Page Controls → Options. Chrome may ask for microphone access the first time.

Activity, console, network and replay are always captured with video. After recording, your review controls are restored.

Review & shortcuts

Start / resume review

Opens Feedbacks and turns review on for the current website after you connect. Chrome manages this shortcut. If it is already taken, choose another combination.

Full-page capture (optional)

P scrolls the page and captures additional images. Use it when the whole page matters. Visible capture already includes the saved original view for each point, including closed menus.

Keep page controls out of the way

Drag the grip to move the Feedbacks dock. Collapse the panel or hide it, then reopen the Chrome extension to restore it. Exit is always available on the dock. Pin the extension using Chrome’s puzzle menu for quick access.
