Feedbacks or FasterFixes?

Both can put visual feedback in an agent's hands. Their deployment paths differ.

FasterFixesChoose FasterFixes if you want a site widget and automatic GitHub issue creation, and its documented services fit your deployment.

FeedbacksChoose Feedbacks if you prefer extension capture, threaded discussion and a complete self-hosted deployment without a required external job or email account.

How the work moves.

Capture

FeedbacksChrome extension: screenshot any supported web page, draw with the pencil and discuss in a project thread.

FasterFixesA website widget captures page, screenshot, selector and browser context.

Hosting & source

FeedbacksApache-2.0 backend, web app, extension, MCP and CLI. Run them with your PostgreSQL and private S3-compatible storage.

FasterFixesThe AGPL-3.0 application can be self-hosted. Its published production guide requires Inngest and a transactional email provider alongside PostgreSQL and object storage.

Coding agents

FeedbacksScoped MCP access to the thread, replies, screenshot and owner-approved reviewer guidance. Expertise weights are advisory.

FasterFixesIts MCP server lets agents read feedback and update status.

Next step

FeedbacksClarify quick requests in the thread. Create and link GitHub Issues through your existing workflow when the work is agreed.

FasterFixesIts GitHub integration can create issues automatically.

What Feedbacks does today.

Feedbacks is an early 0.x product. GitHub Issues and Projects are a manual handoff, not an automatic sync. It does not include video replay, surveys or an AI model subscription. Self-hosting has no Feedbacks license fee; you still pay for your server, database, storage and operations.

Reviewer expertise belongs in owner-approved guidance. A private member note or profile field is not automatically shared with an ordinary agent. Guidance helps interpretation but never grants permissions or guarantees how a model will decide.
