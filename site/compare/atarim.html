Feedbacks or Atarim?

Atarim connects client requests to site work. Feedbacks keeps the review evidence in an open stack.

AtarimChoose Atarim if your agency manages WordPress sites and wants agent-assisted changes inside that ecosystem.

FeedbacksChoose Feedbacks when you want a standalone, self-hosted visual review app for web pages and advisory expertise in MCP context.

How the work moves.

Capture

FeedbacksChrome extension: screenshot any supported web page, draw with the pencil and discuss in a project thread.

AtarimReviewers can pin website comments with screenshots and discuss tasks in context.

Hosting & source

FeedbacksApache-2.0 backend, web app, extension, MCP and CLI. Run them with your PostgreSQL and private S3-compatible storage.

AtarimAtarim provides a workspace and a WordPress plugin for deeper site actions.

Coding agents

FeedbacksScoped MCP access to the thread, replies, screenshot and owner-approved reviewer guidance. Expertise weights are advisory.

AtarimIts MCP connects Claude and Codex to tasks and can act on connected WordPress sites.

Next step

FeedbacksClarify quick requests in the thread. A coding agent with separate GitHub access can create an agreed Issue and link its URL through Feedbacks MCP.

AtarimRequests become assigned tasks within Atarim's agency workflow.

What Feedbacks does today.

Feedbacks is an early 0.x product. An agent can create an Issue using its separate GitHub access and link it here through MCP after the team agrees. Feedbacks does not automatically create or synchronize Issues. It offers opt-in project surveys and NPS, but does not include video replay or an AI model subscription. Self-hosting has no Feedbacks license fee; you still pay for your server, database, storage and operations.

Reviewer expertise belongs in owner-approved guidance. A private member note or profile field is not automatically shared with an ordinary agent. Guidance helps interpretation but never grants permissions or guarantees how a model will decide.
