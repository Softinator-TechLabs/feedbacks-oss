Privacy, by surface.

Feedbacks includes a public website, a browser extension and applications operated by individual teams. The information handled depends on which one you use.

This website

The website code uses no advertising trackers, analytics scripts or account cookies. Its interactive example uses illustrative content in your browser and sends no feedback to an application server. The hosting provider may process normal request information, such as IP addresses and browser details, in access and security logs.

Links to GitHub and Softinator open services with their own privacy practices. If you email us about hosting, we receive the contact information and message you send. Please avoid including credentials or private screenshots.

The browser extension

The extension connects to the Feedbacks server you choose. It stores connection credentials and pending drafts in local extension storage. Review actions can capture screenshots and page context; submitted feedback goes to that server. Review and redact sensitive information before sending. Broad website permission for automatic right-click review is optional.

Review context can include the current page URL and title, viewport size, selected text and element details. Loading existing pins sends page context to your chosen server. With optional automatic review enabled, that lookup can happen when you visit a supported page. The extension does not read Chrome's browsing history. Screenshots, annotations and new comments are uploaded only when you submit them. Optional tab video records without audio after you choose a tab in Chrome's picker. You can preview or discard the short recording before explicitly sending it.

Feedbacks account names, discussions and connection tokens are used to show and authorize your team's reviews. The extension does not sell user data, use it for advertising, or use it to determine creditworthiness. Its use of information received from Google APIs follows the Chrome Web Store User Data Policy, including the Limited Use requirements. No remote executable code is loaded.

You can discard local drafts, disconnect an account and turn off automatic review in the extension. Uninstalling removes its local extension storage. Disconnecting or uninstalling does not delete feedback already submitted to a server; ask its operator to delete that data or revoke a connection. Retention and backup removal depend on that operator's policy.

Your team's application

The organization operating your server controls its user accounts, projects, feedback, screenshot and video storage, access rules and retention. Contact that operator about access, deletion, backups or its applicable privacy policy. Self-hosting does not send your feedback to Softinator automatically.

Contact

For questions about this website, contact support@softinator.ai. For a vulnerability, follow the security reporting instructions.

Optional diagnostics

Console and resource timing collection starts only when you choose it in the extension. The editor lets you inspect and select entries before explicitly sharing them with your Feedbacks instance. Collection is bounded to five minutes, 25 console entries and 50 resource entries. URL credentials, queries and fragments are removed; headers, bodies and cookies are not collected. Redaction is best effort, so review messages and URL paths before sharing. Submitted diagnostics follow your instance operator's access and retention policy.
