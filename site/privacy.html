Privacy, by surface.

Feedbacks includes a public website, a browser extension and applications operated by individual teams. The information handled depends on which one you use.

This website

The website code uses no advertising trackers, analytics scripts or account cookies. Its interactive example uses illustrative content in your browser and sends no feedback to an application server. The hosting provider may process normal request information, such as IP addresses and browser details, in access and security logs.

Links to GitHub and Softinator open services with their own privacy practices. If you email us about hosting, we receive the contact information and message you send. Please avoid including credentials or private screenshots.

The browser extension

The extension connects to the Feedbacks server you choose. It stores connection credentials and pending drafts in local extension storage. Review actions can capture screenshots and page context; submitted feedback goes to that server. Review and redact sensitive information before sending. Broad website permission for automatic right-click review is optional.

Your team's application

The organization operating your server controls its user accounts, projects, feedback, screenshot storage, access rules and retention. Contact that operator about access, deletion, backups or its applicable privacy policy. Self-hosting does not send your feedback to Softinator automatically.

Contact

For questions about this website, contact support@softinator.ai. For a vulnerability, follow the security reporting instructions.
