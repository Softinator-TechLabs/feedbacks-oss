Set up the team once.
Then start reviewing.

The extension connects to your installation. It does not create or host a team server.

  1. DevOps installs the server

    Deploy Feedbacks on your company’s server or cloud infrastructure with HTTPS, PostgreSQL and private file storage. Create the first owner account.

    Server installation guide

  2. Install, pin and connect the extension

    Use Chrome’s Extensions menu to pin Feedbacks. Copy the server URL from Help, paste it into the extension and approve the connection.

    Extension installation guide

  3. The owner prepares projects and people

    Add website origins and project context. Connect the GitHub App if you want Issue tracking. Add members, grant project access and set relevant profiles and responsibilities.

    Project and member setup

  4. Each developer connects their own agent

    Sign in as yourself, create your personal setup prompt and configure MCP in Codex, Claude Code or Antigravity. Ask the agent to read feedback, make the agreed change and report checks.

    Agent setup and first fix

Before you start

Do I need my own server before installing the extension?

Your team needs a running Feedbacks server before anyone can connect or send feedback. DevOps installs it once on your company’s infrastructure. If your team already has one, ask for its URL and your sign-in access.

Does every client need to install a server or connect an AI agent?

No. Clients only need the review access your team provides. For browser capture, use the connected extension. A team can also provide a scoped guest review link when configured. Agent setup is for the developers resolving feedback.

Is GitHub required?

No. Capture and MCP work without GitHub. Install and connect the GitHub App when you want to create Issues from feedback or use optional status sync.

Will the AI agent fix everything automatically?

You choose the work. MCP gives your authorized agent access to feedback and context. The developer asks it to make changes, checks the result and records evidence. Connecting MCP alone does not start fixes.
